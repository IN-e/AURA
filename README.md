# AURA · 声场可视化

一个原生 Windows 11 桌面音频可视化浮窗。单文件、无安装器、无需 .NET / VC++ 运行库，控制面板与声环浮窗均置顶。

## 运行

双击 `AURA.exe` 即可。系统要求：Windows 11（进程级音频捕获需要 Windows 10 build 20348 或更高）。

首次启动后：

1. 点击控制面板里的「更换」，选择要可视化的应用，或选择「系统全部音频」。
2. 在「声环 / 点阵 / 横波」三个页签中调整各自效果；「外观」页调整面板背景、透明度、全局 Bloom，并可直接开启「动态色彩」；「色彩」页选择配色预设、四个色彩角色和动态行为。
3. 「固定浮窗」打开后，浮窗完全不接收鼠标和键盘输入；关闭后，可拖动声环调整位置。
4. 浮窗被拖到屏幕边界外时会自动贴边。控制面板可以最小化到任务栏，关闭控制面板即退出程序。

## 功能

- **应用级音源**：使用 Windows 进程回环捕获（WASAPI Process Loopback），仅获取所选应用及其子进程的声音，不录制麦克风。
- **系统音源**：也可以混音捕获整个桌面输出。
- **五层可视化**：
  - 声环：最外圈仅由频域数据驱动；内层环和外层取相反的径向变化——外圈向外突出时内圈向内凹陷。轮廓以均值为中心做对比度拉伸，可同时出现明显高峰与低谷。
  - 外圈网格：每个采样点都同时绘制径向连接筋和一条斜向连接线，形成参考图中的密集三角网格。
  - 点阵：环状点阵，径向波形与最外圈反相：外圈凸起时点阵向内收缩。
  - 横波：横贯中心的单条时域示波线，使用最近一半时域采样（原生等价于 `analyser.getByteTimeDomainData()`）；保留 1.6.0 的自动增益，两端使用透明渐变淡出，不再有固定端点圆点。
  - 碎片：从外圈向外散发并淡出的半透明三角形/四边形，提供锐锋、宽刃、菱片、斜棱四种模板，以及每片随机选择前四种形状的「随机」模式。碎片绕过 Bloom 单独绘制，且只使用纯色填充、不绘制描边，因此轮廓与内部都是同一片纯色。
- **动态色彩**：在「外观」页开启，使用 Primary（声环）、Secondary（点阵）、Accent（横波）、Glow（中心底光）四个角色驱动整套配色。内置赛博、幽紫、极光、落日、黑白五套预设；任一角色均可直接改 RGB，自动进入自定义模式。
  - 音频驱动：外圈按频谱能量分段映射主色 → 强调色 → 辅色；每段之间使用线性颜色插值，节点处不再硬切；音量影响色相与亮度；低频爆发时提升强调色亮度与饱和度。
  - 时间驱动：色相缓慢偏移，外圈渐变沿圆周流动。
  - 预设切换使用可调时长的插值过渡（默认 500 ms），不会硬切。
- **中心底光**：与外圈尺寸联动的圆形背景光，颜色、相对大小、透明度可独立调整；动态色彩开启时使用 Glow 角色色。
- **音频驱动**：碎片出现频率由音量、频谱变化速度（spectral flux）和节拍共同决定，并提供总频率倍率。
- **全环特性**：采用非镜像的循环频谱，左右轮廓保持不对称；频谱与波形使用阻尼平滑，避免抖动。
- **Bloom**：完全由两层不同半径的 Gaussian Blur 叠加生成，没有固定透明度的宽笔触光晕；范围与亮度均可调。
- **统一参数**：声环/点阵/横波可设置 RGB、大小、变化幅度、波形密度、线宽（40–300%）、透明度与开关；碎片可设置 RGB、大小、频率、透明度、模板与开关；底光可设置颜色、大小与透明度。
- **外观**：圆角、纯色背景、1%–100% 整数透明度、RGB 数值输入、快捷主题，以及全局 Bloom 范围/亮度；无背景模糊。
- **浮窗尺寸**：窗口边界以声环/点阵/横波/底光的视觉核心为基准，仅保留适中的 Bloom 余量，不再为碎片整段漂移预留大边框；拖动更贴近屏幕边缘。
- **整体缩放**：新增「浮窗缩放」（40–200%），一次性缩放全部图层、线宽、点阵、碎片与窗口边界。
- **置顶守护**：每秒重新声明一次置顶层级，最小化/还原全部窗口后也能重新浮到非置顶窗口之上；控制面板始终保持在浮窗之上。
- **交互**：固定后浮窗不再接收任何鼠标/键盘输入，鼠标可穿透到其后的界面；关闭固定后可拖拽，越界自动贴附屏幕边缘。
- **外观预设**：所有修改在停止操作约 0.4 秒后自动写入程序目录，退出时再强制保存；下次启动自动加载。
- **轻量**：原生 C++20、Direct2D / Direct3D 11 / DirectComposition；单文件约 0.4 MB，实测常驻内存约 55–80 MB，60 fps 播放时约占用单核 12%–24%（动态色彩与屏幕分辨率会增加开销）。
- **本地运行**：无网络功能，不上传音频或界面数据。

## 参数说明

| 参数 | 范围 | 作用 |
| --- | --- | --- |
| 颜色 R/G/B | 0–255 整数 | 各效果独立颜色，辉光与线条使用同一色相 |
| 大小 | 效果页内滑杆 | 声环半径 / 点阵半径 / 横波宽度 |
| 变化幅度 | 0–200% | 波形径向或纵向的起伏幅度 |
| 波形密度 | 声环 24–160；点阵 24–180；横波 20–360 | 采样点与绘制密度 |
| 线宽 | 40–300% | 该效果线条、点阵直径与连接网格的粗细 |
| 透明度 | 1–100% | 该效果图层的不透明度 |
| 面板透明度 | 1–100% | 仅控制面板背景；文字和控件保持清晰 |
| Bloom 范围 | 10–200% | 辉光扩散半径；100% 为默认范围 |
| Bloom 亮度 | 0–200% | 辉光强度；0% 关闭 Bloom，100% 为标准亮度 |
| 碎片大小 | 20–200% | 单片碎片的尺寸倍率 |
| 碎片频率 | 0–200% | 基础出现频率倍率；实际频率仍受音频强弱与变化速度调制 |
| 碎片模板 | 锐锋 / 宽刃 / 菱片 / 斜棱 / 随机 | 前四种为固定形状；「随机」让每片碎片从四种模板中随机选择 |
| 底光大小 | 20–200% | 相对于声环尺寸的底光半径 |
| 底光透明度 | 1–100% | 圆形背景光的强度 |
| 浮窗缩放 | 40–200% | 同比缩放整个浮窗的视觉尺寸与窗口边界 |
| 动态色彩 | 外观页开关 | 开启后用四种角色色覆盖声环/点阵/横波/底光的独立颜色 |
| 色彩角色 | 色彩页 RGB | 主色（声环/碎片）、辅色（点阵）、强调色（横波）、发光色（底光） |
| 配色预设 | 赛博 / 幽紫 / 极光 / 落日 / 黑白 | 一键套用经典配色；修改任一角色 RGB 后进入自定义 |
| 动态强度 | 0–200% | 音量色相偏移、亮度和低音爆闪幅度 |
| 流光速度 | 0–200% | 色相漂移与外圈频谱渐变旋转速度 |
| 过渡 | 0–2000 ms | 切换预设或修改角色色时的颜色插值时长 |

数值可以直接点击输入，也可用滑杆和滚轮调整。

## 设置与外观预设

当前外观/效果预设会自动保存到 **AURA.exe 同目录**：

```
<AURA.exe 所在目录>\presets.ini
```

每次修改面板或浮窗参数后约 0.4 秒自动写入，正常关闭程序时再强制保存一次；下次启动会读取该预设。`[color]` 段保存动态色彩角色、预设、行为开关、动态强度和过渡时长。首次升级且程序目录还没有 `presets.ini` 时，会自动从旧位置 `用户文档\AURA\presets.ini` 迁移一次。若程序目录不可写，会依次回退到用户文档的 `AURA\presets.ini`、`%LOCALAPPDATA%\AuraSoundRing\settings.ini` 和临时目录。可在启动前设置 `AURA_SETTINGS_PATH` 环境变量指定自定义配置文件，便于便携或测试。

## 已知限制

- 进程级捕获要求 Windows 11；受保护音频（如某些 DRM 内容）可能只能捕获到静音。
- 极少数带反作弊或特殊保护的应用可能拒绝进程回环；此时可改用「系统全部音频」。
- 若音源应用退出，浮窗会回到空闲波形；重新打开音源应用并重新选择即可。
- 本程序使用项目自签名证书。导入发布包中的证书后，本机可显示已验证的发布者；未导入证书的机器仍可能出现 SmartScreen 提示。

## 从源码构建

依赖：

- Visual Studio 的「使用 C++ 的桌面开发」工作负载（MSVC + Windows SDK 10.0.26100 或兼容版本）
- Windows PowerShell 5.1 或更高

在项目根目录运行：

```powershell
powershell -ExecutionPolicy Bypass -File .\build.ps1
```

产物为 `dist\AURA.exe`。构建使用 `/MT` 静态运行库，所以发布时只需要一个 exe。

主要源码：

```
src/main.cpp            程序入口、窗口生命周期、设置保存
src/audio.cpp           应用枚举、WASAPI 进程回环 / 系统回环
src/analyzer.cpp        FFT、频谱平滑、自动增益、节拍检测
src/overlay.cpp         DirectComposition 浮窗与三层可视化绘制
src/panel.cpp           控制面板交互与输入
src/panel_render.cpp    控制面板渲染
src/settings.cpp        配置读写
src/app.rc / app.manifest / aura.ico
```

面向 Windows 11，使用 Per-Monitor V2 DPI 感知。

## 设计说明

- 频谱来自 2048 点 Hann 窗 FFT，按 38 Hz–17 kHz 对数分带并做峰值归一化与频率倾斜。
- 所有频带经过带惯性阻尼的弹簧滤波器；横波直接读取最近一半时域采样，不做 FFT 或频域插值。
- 最外圈只使用频域数据；内层环和点阵环使用最外圈径向变化的**负值**，所以外圈向外凸起时内圈和点阵同步向内凹陷。层间距另由第三组频带信号调制，每个角点仍受最小间距约束。
- 两层轮廓分别减去自身均值后放大对比度，因此同一帧里可以同时出现外凸高峰和内凹低谷。
- 外圈网格在每个采样角度绘制一条径向筋，再绘制一条连接到下一内圈采样点的斜线；这补回了参考图中垂直方向的连接线，并让网格密度翻倍。
- 频谱按完整一圈循环映射，不做左右镜像，因此轮廓持续保持不对称。
- 点阵环取最外层径向变化的相反值，因此与外层反相起伏。
- 横波取最近一半的时域缓冲，经自动增益后绘制为单条中心示波线；这是 1.6.0 的原始横波逻辑，不包含镜像、滑动平均或死区。波形与中心基线使用水平线性渐变，两端 7.5% 区域透明淡出，避免出现固定端点像素。
- 动态色彩每帧根据当前角色色、音量、低频能量与时间计算最终颜色；外圈频谱渐变由 12 个分段路径组成，每段使用从起点色到终点色的线性渐变，相邻段共享同一个节点色，因此颜色衔接连续。预设切换使用平滑插值，底光颜色按过渡进度以约 80 ms 的间隔刷新缓存。
- 画面先渲染到离屏目标；Bloom 由近距离与远距离两层 Gaussian Blur 合成，分别承担贴线亮边与大范围衰减，再与清晰层叠加。没有额外绘制固定宽笔触的透明光晕。
- 浮窗尺寸由声环/点阵/横波/底光的视觉核心加有限 Bloom 余量计算；不再为碎片整段漂移预留空间。修改「大小 / 变化幅度 / Bloom 范围 / 浮窗缩放」后窗口会自动收紧或扩展。
- 碎片使用独立的粒子系统：黄金角分布避免过度聚堆，出现频率由音量、频谱变化速度（正频谱通量）和节拍驱动；每个碎片沿径向向外运动、旋转并淡出。
- 碎片在 Bloom 之后单独绘制，且只填充纯色、不绘制任何描边，因此不会被主辉光糊成圆团，也不会出现双层边框。
- 底光单独渲染到离屏目标，使用六段径向渐变加 Gaussian Blur 形成柔和衰减，再作为线条之前的第一层背景合成。
- 浮窗边界只给 Bloom 留出有限余量，碎片在远段逐渐透明；这样窗口不会比可见内容大出太多，桌面可移动范围更合理。
- 「浮窗缩放」在 DPI 缩放之外再乘一个全局倍率，所有视觉尺寸和边界同步变化；滑块停止约 0.13 秒后自动调整窗口并保持中心位置。
- 控制面板使用软件 Direct2D 渲染到分层窗口，只在设置改变时重绘，空闲时不做持续绘制。

## 1.5 更新

- 浮窗边界收紧：不再把碎片的整段漂移与三层 Bloom 半径全部计入窗口，默认窗口明显缩小，桌面可移动范围更大。
- 新增「浮窗缩放」滑杆（40–200%），统一缩放所有视觉图层与窗口边界，位于「外观」页。
- 面板高度适配新的缩放控件。
- 添加本地代码签名工具链与证书安装步骤（见下文「数字签名」）。

## 1.5.1 更新

- 中心底光改为独立离屏渲染 + Gaussian Blur 过渡：先绘制平滑的多段径向渐变，再模糊后叠加到主画面，消除了原本可见的圆形硬边。
- 底光不再参与线条 Bloom，避免透明渐变叠加后出现过亮的边圈。
- 底光仍然只在设置或窗口尺寸改变时重绘，不会增加每帧的重复计算。

## 1.6.0 更新

- 基于 1.6.0 的横波逻辑：恢复单条时域示波线，撤销 1.6.1 / 1.7 的镜像、滑动平均与死区处理。
- 新增「动态色彩」：外观页开启，色彩页配置四个角色、五套预设、三个动态行为与过渡时长。
- 外圈支持按频谱能量分段着色，主色 → 强调色 → 辅色形成流光渐变；相邻分段采用线性混色，节点处平滑衔接；低频爆发时强调色增亮。
- 横波两端改为透明淡出，不再绘制固定端点圆点。
- 音量驱动色相和亮度，时间驱动缓慢色相漂移与渐变旋转。
- 预设/角色色切换使用可调 0–2000 ms 的平滑插值。
- 颜色角色：主色 → 声环与碎片；辅色 → 点阵；强调色 → 横波；发光色 → 中心底光。
- 最外圈仍由频域数据驱动；内层环与点阵环仍与最外圈反相。
- 预设文件仍保存在 `AURA.exe` 同目录的 `presets.ini`。

版本：1.6.0

## 数字签名

发布包根目录附带：

- `AURA-CodeSign.cer`：本项目的自签名代码签名证书公钥。
- `Install-AURA-Certificate.cmd`：把该证书导入当前用户的「受信任的发布者」和「受信任的根证书颁发机构」。

首次使用建议右键以当前用户身份运行一次 `Install-AURA-Certificate.cmd`，然后启动 `AURA.exe`。签名可消除「发布者未知」这一层提示。

**限制**：这是自签名证书，不是 CA/EV 证书。SmartScreen 还会结合文件哈希与发布者声誉判断，因此无法保证在所有机器上完全零提示。若要求对所有用户彻底消除 SmartScreen，需要使用 OV/EV 代码签名证书或 Microsoft Store / Azure Trusted Signing 重新签名；本机没有此类证书，无法代为签发。
